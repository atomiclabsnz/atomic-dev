 TERMINAL IDE CHEAT SHEET              (edit: ~/.config/ide/cheatsheet.txt)

 WINDOW (Zellij)   Ctrl-q then a key  —or—  Alt+key in one go
   h / l             focus file tree / editor     /       this help (q close)
   j / k             focus pane below / above     g       git tab
   1 2 3 4           code/claude/git/shell tab    t       terminal below
   c                 claude tab
   z                 fullscreen pane              f       show/hide popups
   d                 detach (session keeps running; `ide` re-attaches)
   q                 quit (kill the session)      Esc     cancel
   Ctrl-g works the same where nothing else grabs it. Ctrl-q twice cancels.
   Quitting Helix or lazygit just restarts it; leave the IDE with d or q.
   Alt keys need your terminal to send Option as Alt (Ghostty: macos-option-as-alt)
   With Alt, quit is Alt Shift q. Mouse clicks also focus panes.

 FILE TREE (Yazi)
   j / k             down / up                    Enter   open in Helix
   h / l             parent / enter folder        .       toggle hidden files
                     (h stops at the project folder)
   a                 new file (end with / = dir)  r       rename
   d                 trash                        y / p   copy / paste
   /                 search in folder             z       jump (fzf)

 EDITOR (Helix)  — press space, g, m, [ or ] and wait: a hint menu appears
   i / a             insert before / after        Esc     back to normal
   w / b / e         select word fwd / back       x       select line
   d / c / y / p     delete / change / yank / put u / U   undo / redo
   space f           find file                    space /  search in project
   space b           open buffers                 Tab      next buffer
   space e           file explorer picker         Ctrl-s   save
   gd / gr           go to definition / refs      space k  hover docs
   space a           code actions                 space r  rename symbol
   space d           diagnostics                  ]d / [d  next / prev error
   space s           symbols in file              Ctrl-o   jump back
   ]g / [g           next / prev git change       space g  changed files
   Ctrl-r            reload after lazygit         :q       quit
   %  s  ,          select all / select regex / keep primary (multi-cursor)

 GIT (Lazygit)        ? inside lazygit shows every key
   Tab / 1-5         switch panels                space    stage / unstage
   c                 commit                       P / p    push / pull
   Enter             view diff                    e        edit file in Helix
   b                 branches                     z        undo
